# SumitayaApp

株式会社祭すみたや様向けの業務支援システム（AIエージェント導入）。

## 構成

- Next.js 16（App Router）＋ TypeScript
- Tailwind CSS
- Supabase（PostgreSQL）※導入予定
- Vercel ※導入予定

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 で確認できる。

## 注意

- 要件定義・設計書・議事録はこのリポジトリに入れない（`すみたやプロジェクト` の各フォルダで管理）。
- すみたや様からいただいた実データ（売上・従業員・入出金など）はコミットしない。
- 環境変数（`.env*`）はコミットしない。
